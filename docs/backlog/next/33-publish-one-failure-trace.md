## Why
An aggregate score persuades nobody. One concrete trace of a model clearing a flight the calculator refused is the artifact a reviewer remembers.

## In scope
- One `unsafe_go` or `invented_number` from a real model
- Coordinates redacted
- Markdown plus the raw JSON, both committed

## Out of scope
- A gallery of failures. One, in full.

## Acceptance
- [ ] README links it
- [ ] Every number in the writeup matches the committed results file

## Test that would have failed before
No individual failure was reproducible from the repository.

# Attic

Earlier repositories that fed this one. They remain available, but they
are not competing planners. This repository is the one to pin.

## [blue_uas_starter](https://github.com/MatthewK84/blue_uas_starter)

Blue UAS Platform Explorer: a specifications browser over the Blue UAS
cleared list. What it contributed is the catalog idea — a set of named
Blue UAS platforms with published limits. This repository kept a smaller,
provenance-backed subset of that catalog as planning reference data.

## [suas-llm-assistant](https://github.com/MatthewK84/suas-llm-assistant)

An earlier FastAPI assistant that retrieved from sUAS documents and
called a language model, with its own eval suite. What it contributed is
the corpus, retrieval, and eval shape. This repository kept those ideas
and put a sealed deterministic calculator in front of the model.

This list is only the public predecessors whose contribution to this
codebase is clear. It does not archive or delete those repositories.
